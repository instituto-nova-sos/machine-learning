# Soluções comentadas — acesso do instrutor

[← Exercícios](../exercicios.md) · [Índice do módulo](../README.md)

Treino ajusta, validação escolhe e teste estima o resultado final. Normalizar com média global é
vazamento. Um contrato deve rejeitar texto e infinito, registrar ausentes e não inventar uma faixa
“universal” sem fonte. A amostra central exclui outras regiões e faixas de renda; localização pode
agir como proxy socioeconômico. Não se deve usá-la para tributação, crédito ou decisões sobre
pessoas. A solução é também limitar a finalidade, não apenas coletar mais linhas.
