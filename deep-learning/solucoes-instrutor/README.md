# Soluções do instrutor

Nível 1: arquitetura, tarefa, família e tarefa, respectivamente. Filtro [−3,1];
estados [2,2]; atenção uniforme dá média de V. LLM não é todo o campo de IA.
Nível 2: use o mesmo par de pesos em cada janela e confira limites de índices.
Recorrência inclui h anterior no cálculo; a MLP recebe só o vetor corrente.
Nível 3: exigir vínculo entre hipótese estrutural e dados. Avaliar baseline,
representatividade, sensores, prevalência, grupos e custo antes de aumentar rede.
