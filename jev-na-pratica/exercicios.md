# Exercícios

## Nível 1 — compreensão

Escolha Choice/Score/Noul para equipe de encaminhamento, prioridade ordenada
 e pedido explícito de humano. Calcule score do README e confidence de Choice.

## Nível 2 — implementação

Execute o fixture offline e modifique-o para distribuição inválida. Compare
probabilidade de opção, confidence e probabilidade de falha; explique por que
nenhuma é autorização. Mantenha a API oficial fora dos testes obrigatórios.

## Nível 3 — investigação

Escreva plano de avaliação em pt-BR com casos ambíguos, opções ausentes, abstenção
 e alta consequência. Opcionalmente, com conta/chave próprias, execute --live,
registre versão e valide contrato, sem usar dados reais ou secrets nos registros.
Explique o que foi verificado offline e o que continuou sem evidência empírica.
