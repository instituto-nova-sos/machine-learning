# Soluções do instrutor

Nível 1: validação decide entre configurações, teste mede a escolhida. 0,20/0,80=0,25.

Nível 2: índices locais precisam ser mapeados aos originais; duas sementes não
substituem disjunção. Copiar arrays evita que atualizações modifiquem o melhor estado.
A derivada de λw² é 2λw. O laço monitora só validação, com paciência fixada antes.

Nível 3: exigir números produzidos pela execução, não uma afirmação universal de
que aumentar profundidade sempre piora. Em grupos, todas as linhas de uma máquina
pertencem ao mesmo conjunto. Em tempo, só o passado pode orientar previsão futura.
Para cada dobra: scaler.fit(treino_da_dobra), transform em treino e validação.
