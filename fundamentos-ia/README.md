# Fundamentos de IA

[← Voltar à aula principal](../README.md) · [Próximo módulo: aprendizagem com dados →](../aprendizagem-com-dados/README.md)

**Pré-requisitos:** lógica, funções Python e estatística descritiva.
**Resultados:** distinguir IA, ML, Deep Learning e LLMs; separar paradigma de aprendizagem,
tarefa e arquitetura; explicar treino e inferência; usar corretamente exemplo, atributo, alvo,
modelo, algoritmo, parâmetro, hiperparâmetro e métrica; avaliar quando ML é inadequado.

## Pergunta orientadora

Quando um sistema produz uma saída, o que foi programado diretamente e o que foi ajustado a partir
de dados? Responder bem exige identificar o problema, a evidência usada, o objetivo matemático e
as consequências dos erros — não apenas reconhecer o nome de uma biblioteca.
