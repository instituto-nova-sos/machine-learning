Previsões `[2,3]`, resíduos `[1,2]`, MSE `(1+4)/2=2,5`. Uma taxa pequena reduz a perda devagar;
uma grande pode oscilar ou divergir. A versão NumPy deve manter formas explícitas. Concordância
entre implementações verifica parte do cálculo, não representatividade, causalidade, estabilidade
temporal, finalidade ou riscos. Aceite pequenas diferenças numéricas com tolerância.
