O MSE é `(1+0+1)/3=2/3`. A derivada é `8x+3`. Distância: raiz da soma dos quadrados das diferenças.
`h=0` divide por zero; `h` pequeno demais amplifica cancelamento e arredondamento. Para
`(2x-1)³`, a derivada externa é `3(2x-1)²` e a interna é 2, logo `6(2x-1)²`.
